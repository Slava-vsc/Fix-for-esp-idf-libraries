бібліотека працює з ядром 3.0.5
-------------------------------
При використанні Arduino 1.8.19, скопіювати файли liblwip.a та libesp_netif.a в папку:

для ESP32-S3:   
C:\Users\User\AppData\Local\Arduino15\packages\esp32\hardware\esp32\3.0.5\tools\sdk\esp32s3\lib

для ESP32 WROOM, ESP32 WROVER:   
C:\Users\User\AppData\Local\Arduino15\packages\esp32\hardware\esp32\3.0.5\tools\sdk\esp32\lib

При використанні Visual Studio Code, скопіювати файли liblwip.a та libesp_netif.a в папку:

для ESP32-S3:   
C:\Users\User\AppData\Local\Arduino15\packages\esp32\tools\esp32s3-libs\3.0.5\lib

для ESP32 WROOM, ESP32 WROVER:   
C:\Users\User\AppData\Local\Arduino15\packages\esp32\tools\esp32s3-libs\3.0.5\lib

-- шляхи можуть відрізнятися --
