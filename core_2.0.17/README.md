При використанні Arduino 1.8.19, скопіювати файл liblwip.a в папку:

для ESP32-S3:

C:\Users\User\AppData\Local\Arduino15\packages\esp32\hardware\esp32\2.0.17\tools\sdk\esp32s3\lib

для ESP32 WROOM, ESP32 WROVER:

C:\Users\User\AppData\Local\Arduino15\packages\esp32\hardware\esp32\2.0.17\tools\sdk\esp32\lib

При використанні Visual Studio Code, скопіювати файл liblwip.a в папку:

для ESP32-S3:

C:\Users\User\.platformio\packages\framework-arduinoespressif32\tools\sdk\esp32s3\lib

для ESP32 WROOM, ESP32 WROVER:

C:\Users\Slava\.platformio\packages\framework-arduinoespressif32\tools\sdk\esp32\lib
